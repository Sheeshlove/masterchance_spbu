# Как это запустить

Инструкция «с нуля»: считаем, что вы никогда ничего не устанавливали и не
открывали ничего страшнее браузера. Каждый шаг расписан отдельно.

> **Сначала прочитайте это.**
> Программа `MasterChance.exe` **сама по себе пока не появится** — её нужно
> один раз собрать, а данные для неё один раз выложить. Это делает владелец
> проекта, и это **Часть 2**. Пока Часть 2 не сделана, программа при запуске
> честно скажет, что данных нет.
>
> - Вы **абитуриент** и вам дали ссылку на готовую программу → **Часть 1**.
> - Вы **владелец проекта** и хотите, чтобы всё заработало → **Часть 2**.
> - У вас **нет .exe** и вы готовы запустить из исходного кода → **Часть 3**.

## Часть 1. Для абитуриента: посмотреть свои шансы

### Что вам понадобится

- компьютер с **Windows** или **macOS** (Mac);
- **уникальный код поступающего** — это число, которое вам выдали при подаче
  документов (например, `1645144`). Он же написан в списках на сайте вуза;
- интернет (хотя бы на первый запуск).

### Шаг 1. Скачайте нужный файл

Откройте ссылку, которую вам дали (страница **Releases**). Там будет несколько
файлов — выберите **один**, подходящий вашему компьютеру:

| У вас | Скачивайте |
| --- | --- |
| Windows | `MasterChance.exe` |
| Mac с чипом **Apple M1/M2/M3/M4** | `MasterChance-macos-apple-silicon.zip` |
| Mac с процессором **Intel** | `MasterChance-macos-intel.zip` |

> **Как понять, какой у вас Mac?** Нажмите значок 🍎 в левом верхнем углу →
> **«Об этом Mac»**. Если в строке написано **«Чип: Apple M…»** — это Apple
> Silicon. Если **«Процессор: Intel…»** — значит Intel.
> Если скачать не тот файл, программа просто не запустится — тогда скачайте
> второй.

Файл окажется в папке **«Загрузки»** (*Downloads*).

### Шаг 2. Запустите программу

#### Если у вас Windows

1. Откройте папку «Загрузки» и **дважды щёлкните** по файлу `MasterChance`.
2. Скорее всего появится синее окно *«Система Windows защитила ваш компьютер»*.
   Это **нормально**: так Windows реагирует на любую программу без платного
   сертификата. Нажмите **«Подробнее»**, затем **«Выполнить в любом случае»**.

Если антивирус тоже ругается — причина та же.

#### Если у вас Mac

1. Откройте папку «Загрузки» и **дважды щёлкните** по скачанному `.zip` — рядом
   появится приложение **MasterChance**.
2. Перетащите его в папку **«Программы»** (*Applications*). Так удобнее, но
   можно запускать и из «Загрузок».
3. **Первый запуск — особый.** Обычный двойной клик macOS не пропустит: она
   скажет, что не может проверить разработчика. Сделайте так:
   - **щёлкните по значку правой кнопкой** (или удерживая **Control**) →
     выберите **«Открыть»**;
   - в появившемся окне ещё раз нажмите **«Открыть»**.
4. **Если кнопки «Открыть» нет** (так бывает на новых версиях macOS): откройте
   🍎 → **«Системные настройки»** → **«Конфиденциальность и безопасность»**,
   пролистайте вниз — там будет строчка про заблокированное приложение
   MasterChance и кнопка **«Открыть всё равно»**. Нажмите её.

Дальше приложение будет открываться обычным двойным кликом.

> **Почему macOS ругается?** У приложения нет подписи Apple — она платная
> (99 $ в год). Программа от этого не хуже и не опаснее, но систему надо один
> раз убедить. Если вы не доверяете источнику ссылки — лучше не запускать.

### Шаг 3. Подождите несколько секунд

Откроется окно с заголовком **«MasterChance — посмотри свои шансы»**.

Внизу, под кнопками, есть **серая строчка** — это «статус». Сначала там будет
написано *«Проверяем обновление данных…»*, потом *«Скачиваем данные…»*, а через
несколько секунд — *«Данные загружены: <дата и время>. Готово к поиску.»*

Дождитесь именно последней надписи. Пока идёт загрузка, кнопки не нажимаются —
это тоже нормально.

### Шаг 4. Введите свой код

1. Щёлкните в **белое поле** слева (курсор там уже мигает).
2. Наберите свой код с клавиатуры — только цифры, без пробелов.
3. Нажмите кнопку **«Показать шансы»** или просто клавишу **Enter**.

### Шаг 5. Прочитайте результат

В большом белом поле появится список ваших направлений. Для каждого написано:

| Что написано | Что это значит |
| --- | --- |
| **Название направления** | куда вы подали документы |
| **Шанс зачисления: 41.7%** | из 10 000 «предсказанных будущих» вы поступили сюда примерно в 4 170 |
| **Проходной (90–95%): 222 – 226** | сколько баллов, скорее всего, хватит, чтобы пройти |
| **Сдан: 99+3=102** | ваш балл за экзамен, плюс баллы за достижения, и сумма |
| **Расписание экзамена пока не опубликовано** | балла ещё нет. СПбГУ не публикует даты испытаний в тех списках, которые читает программа, поэтому дат здесь не будет — смотрите их на сайте вуза |
| **Сейчас: балл …, приоритет …, согласие …** | это подтянулось **прямо сейчас** из списков вуза |
| **«Пролетел с магой»: 56.0%** | вероятность, что не пройдёте никуда из этого списка |

Внизу серая строка напишет одно из двух:

- *«Готово. Ваши баллы обновлены только что»* — свежие данные получены;
- *«Готово. Актуальные баллы получить не удалось — показаны данные снапшота»* —
  интернет не дал забрать свежее, показано последнее известное.

> **Важно понимать.** Проценты — это **прогноз**, а не обещание. Программа не
> знает, куда ещё подали документы другие люди и кто в итоге передумает.

### Шаг 6. Если хотите обновить данные

Нажмите кнопку **«Обновить данные»**. Программа сходит в интернет и заберёт
свежий расчёт. Само по себе это происходит примерно раз в 6 часов.

### Мелочи, которые полезно знать

- Программу **не нужно устанавливать** — она просто запускается из файла.
- Данные она сохраняет у вас на компьютере, в папке
  `C:\Users\<ваше имя>\AppData\Local\MasterChance`. Эту папку можно удалить —
  ничего не сломается, программа скачает всё заново.
- Без интернета программа тоже откроется и покажет последние сохранённые данные,
  честно предупредив об этом.

## Часть 2. Для владельца: сделать так, чтобы Часть 1 заработала

Нужно сделать **две вещи**: собрать программу и выложить данные.

> Обе задачи делаются на сайте GitHub, в браузере. Ничего устанавливать не надо.

### 2.1. Собрать `MasterChance.exe`

1. Откройте страницу проекта на GitHub.
2. Сверху есть строка вкладок: `Code`, `Issues`, `Pull requests`, **`Actions`**.
   Нажмите **`Actions`**.
3. Слева в списке выберите **`Build desktop client`**.
4. Справа появится серая полоска с надписью **`Run workflow`**. Нажмите на неё,
   потом на зелёную кнопку **`Run workflow`** внутри.
5. Ждите. Появится строчка с крутящимся жёлтым кружком — идёт сборка
   (примерно 3–7 минут). Жёлтый кружок сменится на **зелёную галочку**.
6. Щёлкните по этой строчке. Внизу страницы будет раздел **`Artifacts`**, а в
   нём **три файла** — по одному на каждую систему:
   - `MasterChance-windows` — для Windows;
   - `MasterChance-macos-apple-silicon` — для Mac с чипом M1/M2/M3/M4;
   - `MasterChance-macos-intel` — для Mac на Intel.

   Нажмите на нужный — скачается архив с программой.

Если вместо галочки появился **красный крестик** — сборка не прошла. Щёлкните
по строчке и посмотрите, на каком шаге ошибка. Сборки под разные системы
независимы: если упала одна, остальные всё равно соберутся.

> **Внимание:** файлы в разделе `Artifacts` GitHub хранит только **90 дней**, и
> скачать их может лишь тот, кто вошёл в GitHub. Чтобы дать программу
> абитуриентам постоянной ссылкой, приложите её к релизу (см. 2.2) — при
> публикации тега вида `v1.0` сборка кладёт файлы в релиз автоматически.

### 2.2. Выложить данные (снапшот)

Программа не считает вероятности сама — их слишком тяжело считать на обычном
компьютере (нужно смоделировать конкурс **всех** абитуриентов сразу). Поэтому
расчёт делается один раз на сервере, а программа скачивает готовый результат.
Этот готовый результат и называется **снапшот**.

> 📘 **Это делается на отдельном сервере, а не на вашем компьютере.** Как его
> завести, настроить и включить автообновление — отдельная подробная
> инструкция: **[СЕРВЕР.md](СЕРВЕР.md)**. Ниже — только суть.

Нужно выполнить **две** команды (не три: `update_lists.py` уже пересчитывает
вероятности сам, отдельный `run_monte_carlo.py` после него — это лишние
10 000 симуляций):

```bash
python update_lists.py      # скачать списки + посчитать вероятности
python build_snapshot.py    # упаковать результат
```

Появится файл **`dist/master-snapshot.db.gz`**. Выложить его на GitHub можно
одной командой (сервер сделает всё сам — создаст релиз, удалит старый файл,
зальёт новый):

```bash
scripts/publish_snapshot.sh
```

> **Два условия, без которых программа не найдёт данные:**
> 1. файл должен называться **ровно** `master-snapshot.db.gz`;
> 2. репозиторий должен быть **публичным** — иначе ссылка потребует пароль,
>    а программа его вводить не умеет.
>
> Снапшот всегда лежит в одном релизе с постоянным тегом **`data`**, поэтому
> ссылка на него никогда не меняется:
> `https://github.com/Sheeshlove/masterchance_spbu/releases/download/data/master-snapshot.db.gz`
> Выпуск новых версий приложения её не ломает.

### 2.3. Обновлять данные потом

Ничего не делать: на сервере стоит расписание, и данные обновляются сами
каждые 6 часов (см. [СЕРВЕР.md](СЕРВЕР.md), шаг 11). Программу пересобирать
при этом **не нужно** — она сама заметит свежие данные.

## Часть 3. Запустить без .exe, из исходного кода

Подходит, если .exe ещё не собран, или у вас macOS / Linux.

### Шаг 1. Установите Python

1. Откройте сайт **python.org**, раздел **Downloads**.
2. Нажмите большую жёлтую кнопку **`Download Python 3.x`**.
3. Запустите скачанный файл.
4. **Самое важное.** В самом первом окне, внизу, есть квадратик
   **`Add python.exe to PATH`** — **поставьте в нём галочку**. Без неё
   компьютер потом «не найдёт» Python.
5. Нажмите **`Install Now`** и дождитесь надписи *Setup was successful*.

### Шаг 2. Скачайте код проекта

1. На странице проекта нажмите зелёную кнопку **`Code`**.
2. В выпавшем списке выберите **`Download ZIP`**.
3. Найдите скачанный архив в «Загрузках», щёлкните правой кнопкой →
   **«Извлечь всё»** → **«Извлечь»**.

### Шаг 3. Откройте «чёрное окно» в папке проекта

Это окно называется командной строкой. Самый простой способ:

1. Откройте распакованную папку (внутри должны быть файлы `desktop.py`,
   `bot.py`, `README.md`).
2. Щёлкните мышкой в **адресную строку** сверху — туда, где написан путь к папке.
3. Весь путь выделится синим. Наберите вместо него три буквы **`cmd`** и нажмите
   **Enter**.

Откроется чёрное окно. Оно уже «стоит» в нужной папке.

### Шаг 4. Установите то, что нужно программе

Напечатайте в чёрном окне ровно эту строку и нажмите Enter:

```
pip install -r requirements-desktop.txt
```

Побежит текст. Дождитесь, пока он остановится и появится слово `Successfully`.

### Шаг 5. Запустите

```
python desktop.py
```

Откроется то же самое окно, что и в Части 1. Дальше — Шаги 3–5 из Части 1.

> **На Linux** дополнительно нужен пакет с оконной библиотекой:
> `sudo apt install python3-tk`. Без него будет ошибка
> `No module named 'tkinter'`.

## Часть 4. Бот и сайт

Это для владельца проекта — обычному абитуриенту сюда не надо.

**Telegram-бот.** Нужен токен от [@BotFather](https://t.me/BotFather). Создайте
рядом с `bot.py` файл `.env` со строчкой `BOT_TOKEN=ваш_токен`, затем:

```bash
pip install -r requirements.txt
python bot.py
```

**Сайт.** Открывается в браузере по адресу `http://localhost:8080`:

```bash
pip install -r requirements.txt
python web.py
```

**Всё сразу в Docker:**

```bash
make compose-up
```

## Что делать, если что-то пошло не так

| Что вы видите | Что это значит и что делать |
| --- | --- |
| Синее окно «Система Windows защитила ваш компьютер» | Обычное предупреждение. «Подробнее» → «Выполнить в любом случае». |
| **Mac:** «Не удаётся проверить разработчика» | Ожидаемо, приложение без подписи Apple. Правая кнопка по значку → «Открыть» → «Открыть». Если такой кнопки нет — Системные настройки → «Конфиденциальность и безопасность» → «Открыть всё равно». |
| **Mac:** «Программа повреждена и её нельзя открыть» | Обычно значит, что скачан файл не для вашего процессора. Проверьте 🍎 → «Об этом Mac» и скачайте другой вариант (Intel ↔ Apple Silicon). Если Mac правильный, откройте «Терминал» и выполните: `xattr -dr com.apple.quarantine /Applications/MasterChance.app` |
| **Mac:** вместо окна открылся Терминал | Вы запустили не приложение, а внутренний файл. Нужен именно значок **MasterChance** из распакованного архива. |
| «Не удалось скачать данные и нет локальной копии» | Снапшот не выложен или репозиторий закрыт. См. **2.2**. |
| «Нет связи — работаем на сохранённых данных» | Нет интернета. Программа работает, но цифры не самые свежие. |
| «Заявок для кода … не найдено» | Опечатка в коде, либо снапшот старее, чем ваша заявка — нажмите «Обновить данные». |
| «Актуальные баллы получить не удалось» | Свежие личные данные не забрались. Шансы всё равно показаны, они из снапшота. |
| `'python' is not recognized` / «не является внутренней командой» | При установке Python не поставили галочку **Add python.exe to PATH**. Переустановите (Часть 3, шаг 1, пункт 4). |
| `No module named 'tkinter'` | Linux: `sudo apt install python3-tk`. |
| `No module named ...` (что-то другое) | Не выполнен шаг 4 Части 3: `pip install -r requirements-desktop.txt`. |
| Окно открылось, но кнопки серые | Идёт загрузка данных. Подождите, пока в серой строке появится «Готово к поиску». |

## Коротко, одной картинкой

```
   ВЛАДЕЛЕЦ (один раз)                        АБИТУРИЕНТ (каждый раз)
   ───────────────────                        ───────────────────────
   update_lists.py      скачать списки
   run_monte_carlo.py   посчитать шансы
   build_snapshot.py    упаковать          →  скачать MasterChance.exe
   выложить в Releases                     →  двойной щелчок
   Actions → собрать .exe                  →  ввести свой код
                                           →  увидеть проценты
```
